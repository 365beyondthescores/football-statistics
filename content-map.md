Why?

### Example

A football match can finish 1–1 while the underlying chance quality tells a very different story.

That is one reason analysts use Expected Goals (xG).

xG estimates the probability that a shot will result in a goal.

# Distribution Principle

Each platform should provide a native version of the same idea.

Do not simply copy the complete GitHub article to every platform.

The core concept remains consistent while:

- The format changes
- The length changes
- The opening changes
- The audience interaction changes
